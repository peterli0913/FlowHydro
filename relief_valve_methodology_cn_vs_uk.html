1️⃣ 规范基础 ｜ Code basis

主要执行规范 • GB 150 压力容器（设计压力、附件配置）
• HG/T 20570 化工装置安全阀设置规定
• HG/T 20557 化工装置工艺系统设计规定
• SH/T 3007 石油化工储运系统罐区设计
• API 520 / 521 / 526 多作为参考（不强制全套） 		• ASME BPVC Section VIII Div. 1（设备）
• API 520 Part I & II（计算 + 安装）
• API 521（系统级泄放与减压）
• API 526（法兰式 PRV 标准化）
• DSEAR / ATEX（防爆评估）
• HSE PUWER / DSEAR / COMAH 整体安全监管
通常引用 DIERS？ 少 — 仅在专门有"反应性物质 / 反应失控"考虑时偶尔引用 必引 — 反应器、釜式反应、闪蒸罐都按 DIERS / Omega 方法判定 single-phase / two-phase
差距：UK 把 DIERS 作为"对反应性系统的默认基线"，中方习惯先用 API 520 单相算、再用工程经验余量来"兜底"。 对话时不要争对错，要主动声明"我们这次按 DIERS Omega 同步重算并 cross-check API 520 结果"。

2️⃣ 泄放工况识别 ｜ Scenario identification

常考虑的工况 国内多数项目典型 4–6 个工况：
  1. 外部火灾（API 521 Fire case）
  2. 冷媒失效（loss of cooling）
  3. 出口阀误关 / 堵塞（blocked outlet）
  4. 仪表控制失效（control failure）
  5. 热膨胀（thermal expansion，液体管线）
  6. 仅供货 PRV 时 — 由供应商按"额定流量 + 余量"选型
 UK 工程公司要求"穷尽 credible scenarios"，常见 10–15 个：
  1. External fire (pool fire)
  2. Loss of cooling / quench failure
  3. Blocked outlet (各种位置)
  4. Control valve failure (FO / FC 两种)
  5. Thermal expansion
  6. Tube rupture (换热器)
  7. Reaction runaway ← 反应系统必须
  8. Power failure (各种连锁后果)
  9. Inadvertent reactant addition
  10. Inadvertent isolation (人误)
  11. Gas breakthrough (上游气进液系统)
  12. Vacuum (失压情形)
  13. External jet fire (邻近设备影响)
每个工况要写什么 通常只为"被选中"的工况写一段，未选的不解释 每个工况都要写：要么计算，要么给"不需计算"的理由（preceded / non-credible / lower than another case）。"未列出 = 没考虑"是不被接受的
差距：Keith 在 05-12 会议明确说"我会把不算的工况也写在 events identification 里，并说明为什么不算"。 中方目前只列了算了的工况。
对策：胡超群在重做计算报告时，把 13 个标准工况都列出来；不算的逐一写一句"preceded by case X" / "lower magnitude than case Y" / "not credible because..."。

3️⃣ 计算方法论 ｜ Sizing methodology

单相还是两相？ 默认单相：火灾 / 冷媒失效都按气化后纯气相算（API 520 Eq. 3.3 / 3.4）； 液体工况按液相 orifice。
逻辑：温度足够高 → 溶剂全气化 → 简化为单相 		反应器、闪蒸罐默认两相：用 DIERS Omega 方法或 SuperChems 算
逻辑：泄放瞬间气液不会立刻分离，二相同时排出，需要的口径比纯气大 1.5–5×
关键公式
// 单相气体 API 520 (Section 5.6) A = W / [ C·Kd·P1·Kb·Kc · √( M/(T·Z) ) ] W = 泄放量 (kg/h); P1 = 泄放压力 (kPa abs) C = 气体系数 (k 函数); Kd = 排放系数 (~0.975) Kb = 背压修正; Kc = 旁通修正 M = 摩尔质量; T = 排放温度; Z = 压缩因子
// 两相 DIERS Omega 方法 (Leung 1986) G_max = P0·√(α0/(ω·v0)) // kg/m²s 质量通量 ω 系数 = α0·(1-α0)·v0g/v0 + (...) α0 = inlet void fraction v0 = 入口比容 A = W / (Kd · G_max)
// 容器内流型判定（Fauske, 1988） ψ = jg_∞ / (vbubble · α_avg) ψ < 1 → Homogeneous（最坏，全两相） ψ > 5 → Churn-turbulent（顶部分离气）
阻塞流判定 国内自编 Excel 多数不显式判定，按公式选用 必须显式判定：P2/P1 < Pcrit/P1 → choked，独立公式；要在报告里写出 critical pressure ratio
入口压降 / 出口背压 通常用 10% 默认值简化 必须核算管路 ΔP：
• 入口 ≤ 3% set pressure（否则 chatter）
• 出口 ≤ 10% set（否则换 balanced bellows 或 pilot-operated）
• 长排放管要算 isothermal/adiabatic compressible flow
差距 + 对策：我们这次必须按 DIERS Omega 同步重算两相结果， 把单相 API 520 当作 sanity check。两个数据并列写在报告里，让 Keith 看到我们覆盖了"他要的方法"。
预期：两相算出来的口径会比单相大 1.5–3×， 现有 1.22 m²（单相）可能升到 2.0–3.5 m²。这是合理的，不是我们之前算错。

4️⃣ 文档格式 ｜ Deliverable format

交付物 • 安全阀数据单（一表一阀）
• 安全阀设置一览表（设置压力、口径汇总）
• 必要时一份计算说明书（PDF, 数页, 简要） 		• Relief Design Study (RDS)：通常 30–100 页
每台 PRV 一节，包含：
　— Equipment data & design conditions
　— Scenario identification (含未算工况的理由)
　— Per-scenario calc：assumptions + equations + intermediate values + result
　— Reference 嵌入 (Excel / Mathcad / SuperChems output)
　— Independent reviewer 复算痕迹
复算可追溯性 公式常隐藏在 Excel 单元格里，只显示数字 必须可独立复算：报告要让人凭文档就重做一遍；典型做法是 Mathcad 报告导出 PDF
假设页 通常无单独"Assumptions"章节 必须有：含溶剂物性、火灾热通量来源、初始 P/T、设备 wetted area 计算、容器内液位假设等
差距 + 对策：胡超群本周内要做： ① 把 Excel 公式全部展开成可见行； ② 单独建一个 "Assumptions" Sheet； ③ 每个工况单独一节（即使没算）； ④ 整套导出为 PDF 作为 RDS Reference 附件。

7️⃣ 常见跨文化坑 ｜ Common pitfalls bridging CN ↔ UK

坑 1 "我们用工程经验取保守值"不被 UK 接受 — 必须明确写出每个保守假设的来源 + 量化值。 例如不能写"考虑余量取 1.2"，要写"按 API 521 §5.15.2.2 火灾热通量 q = 22 kW/m² (适用 prompt fire-fighting)，加 20% 保守余量"。
坑 2 "PRV 数据单上只写一个尺寸"不够 — UK 数据单要列：set P / accumulation %（10/16/21）/ rated flow / required orifice area / next-standard orifice (D/E/F...) / inlet ΔP / outlet back-pressure / 阀类型（balanced bellows / pilot）。
坑 3 "火灾工况按整个设备表面积算"过保守，UK 按 API 521 wetted area 计算（仅含液面以下 + 7.6 m 内）。
坑 4 认为 API 520 单相结果再加 20% 余量 = 两相结果。错。两相要的口径可能是单相的 1.5–5×，不是线性放大。
坑 5 "出口管随便接"—UK 要做 flare network 反算，长排放管会让背压超 10% set，意味着原选阀型号不对，要换 balanced bellows 或 pilot-operated。

7 Thermal expansion 液段管两阀间被关 → 太阳暴晒 / 加热 必算 · 各管段 PSV-30 类 small thermal valves
