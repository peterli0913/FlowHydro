01 核心判断

CE 不是发运前补的“出口贴纸”， 而是认证供应商全程参与 设计审核 → 采购前指导 → 生产复验 → 工厂验收， 最终得到符合性闭环。

可复用的做法不是“临近发货再找机构出证”，而是把认证供应商嵌进制造主线： 前四步有其持续参与，最后一步完成 DoC / 证书、铭牌与说明书的一致闭环。

02 科普精要

CE 标志解决什么问题

CE（Conformité Européenne）是产品进入欧盟市场流通的强制性符合性标识。 它表明制造商声明：该产品已满足所适用欧盟“新方法”指令中的基本健康、安全与相关要求。 对出口方而言，CE 的实质工作是识别适用指令 → 完成合格评定 → 形成技术文件与符合性声明 → 正确加贴标识，而不是单纯“拿一张证”。

指令与标准：谁强制、谁支持

指令（Directive）
  • 具有法律强制力，规定产品类别与基本安全要求（EHSR）
  • 决定是否需要、以及需要何种合格评定路径
  • 同一产品可同时落入多条指令
协调标准（Standard）
  • 提供更细的技术路径，用于证明满足指令要求
  • 原则上属支持性、可选用的符合证据工具
  • 按适用标准设计与验证，是最常用的符合路径
关键原则：当产品同时受多条指令覆盖时，必须全部符合后才能加贴 CE；只满足其中一条不够。

两类常见输出：DoC 与公告机构评估

DoC 符合性声明

由制造商签署（Declaration of Conformity）。声明产品符合所列指令与标准，是加贴 CE 的核心法律文件之一，通常还需明确欧洲代表等信息。

公告机构（Notified Body, NB）

在指令要求第三方介入时，由获欧盟授权编号的机构开展型式评估、体系审核、验证等，并在授权范围内出具相应评估/证书。

是否必须走 NB，取决于指令与产品风险类别（合格评定模块）。低风险路径可能以制造商内部生产控制 + DoC 为主；承压、防爆等高风险场景更常需要第三方介入。 选型机构时，应核对授权范围是否覆盖对应指令与产品类型。

成套撬装常见相关指令（概念层）

MD / ATEX / EMC / PED
  • MD：机械与成套装置的基本健康与安全要求
  • ATEX：用于潜在爆炸环境的设备与保护系统
  • EMC：设备不产生过度电磁干扰、且具备抗扰能力
  • PED：承压设备及承压装置的设计制造与合格评定
理解时避免两个混淆
  • 单体有证 ≠ 整橇自动合规：成套边界、接口与系统风险仍需整体评估
  • CE 合规 ≠ 现场即可投用：属地安装检查、SAT 等属于另一工作层

市场准入与属地监管的差别

英国脱欧后存在 UKCA 等体系差异，具体适用需按目标市场确认。 更通用的经验是：出口前符合性工作解决的是产品以何种身份合法进入市场； 属地安装与使用监管解决的是到场后如何组装、检查与投用。两者相关，但不宜混为一个包干事项。

03 指令组合：先做正确划定

以“整体撬装、含设备/机泵/仪表/阀门/管线/电控、涉氢、防爆场所”为典型场景的实践划定。

MD 机械指令

覆盖撬装作为机械/成套装置的基本健康与安全要求，是整橇符合性的底座之一。

ATEX 防爆指令

电气设备须具备可用的 CE-ATEX 证据链（声明、说明书、铭牌等）；非电设备亦可接受满足指令的供应商 DoC。

EMC 电磁兼容

电控系统是关键抓手。主电柜说明、关键元器件符合性与系统级干扰抑制，应在设计阶段纳入。

PED 承压设备

单体压力容器与整体装置级 PED 往往并存；介质与操作条件直接影响划类与合格评定路径。

实践做法

先问“什么作为一件产品进入市场”

整橇作为成套装置认证，与“只认证单体设备再现场拼装”是两条路径。边界不清会导致后期文件、铭牌、责任主体全部返工。

噪声等项：设计抑制优先

对某些环境类要求，优先在设计中落实抑制措施；是否需要专项认证，按机构评估结论执行，避免默认“全部都要专项证”。

04 认证边界：清关前符合性 ≠ 属地验收

工作层 覆盖内容 经验要点
清关前 CE 工作 设计审核、采购前指导、生产复验、测试、整改、发证/符合性文件闭环 认证机构可深度介入制造端；这是出口前可控的主战场。
属地安装与使用 分块组装、保温、上下游管线与电控连接；属地监察机构检查；SAT 现场验收 与 CE 清关前工作不在同一范畴；不宜默认由同一认证方包办。
可复用结论：合同与计划里要把“出口符合性”和“现场投用验收”拆成两条线，分别定义责任方、交付物与窗口期。

06 文件接口包

机构核算认证路径、工作量和周期，依赖一套“可评审的产品定义文件”。经验上，宜尽早按接口包组织，而不是零散补交。

基础定义文件
  • 完整 P&ID（建议同步标注介质信息）
  • 设备、机泵、阀门、仪表等明细表
  • 撬装布置 / 3D 图纸
  • 主电柜说明（服务 EMC 评审）
风险与材料证据
  • HAZOP 分析报告（可参与复核）
  • 金属材料材质报告
  • 涉氢兼容与材料等级要求的设计依据
  • 关键供应商符合性声明与说明书/铭牌信息
