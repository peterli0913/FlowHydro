📐 配置示意图 ｜ Configuration drawings

A. Demister（从气里除液滴）
Vapour–Liquid Knock-out / De-misting separator
工艺含义：反应器出口的"湿氢气 + 液滴"经侧入 → vane 撞击除粗液滴 → 气体上行经丝网除沫器除细液滴 → 干燥气体顶部出 → 收集的液体重力落入底部 pool → 液相出口。
B. Degasser（从液里脱出气泡）
Liquid de-gasser / De-aerator
工艺含义：含气液体经深管深入到液面以下排出 → 气泡靠浮力慢慢上浮穿过液柱到达液面 → 释放的气从顶部出 → 脱气后的液体从底部出。液柱深度和停留时间是关键。

🎯 SE01 应该用哪种？我们的结论

结论：SE01 应该是 Demister（A 方案）。
工艺逻辑：连续氢化 →反应器出口为"未消耗的 H₂ + 反应液混合"→ 进 SE01 后干气要走顶部 process vent， 液相走底部进 BT04。这是典型的"从气里除液滴"过程，不是"从液里除气"。 现有 PID 上的 dip-pipe 是聂博/Yongguang 早期版本的遗留错误，需要修正。
