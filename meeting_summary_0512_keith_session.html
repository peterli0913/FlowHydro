🧪 技术背景速学 ｜ Technical primer
概念关键点
API 5201960s 起的标准，默认单相（纯气或纯液）泄放。气体走 choked-flow 公式，液体走 orifice 方程。系统真的是两相 + 反应放热时，API 520 不够。
两相流泄放泄放瞬间气液同时排出，需要的截面通常比纯气大 1.5–5×。Keith 担心的就是偏小。
DIERS 方法AIChE 1985 年成立的项目，专门解决两相反应失控泄放。把系统分为 gassy / vapour / hybrid，又分 tempered / untempered。Keith 提到 "homogeneous tempered / hybrid" 就来自这个体系。
Homogeneous vs Churn-turbulent容器内两相流流型。Homogeneous = 气液均匀混合（最坏情况，泄放出来全是两相），Churn-turbulent = 顶部能分离一些气出来（不那么坏）。Keith 取 homogeneous = 最保守。
Choked flow（阻塞流）上下游压差大到一定程度，气速到声速，再加大压差流量不变 — 公式不同，要分类判断。
3% 入口压降 / 10% 出口背压API 设计规范：PSV 入口管路压降 ≤ 3% set pressure（避免颤振），出口背压 ≤ 10% 否则要换 balanced-bellows 阀，再加上长排放管的额外背压都要算进去。

🧪 Fail-closed vs Fail-open ｜ 工程取舍
类型失气 / 失电时典型用法
Fail-closed (FC)阀回到关闭位防外泄 / 防超量加料（向大气排放线、加料阀）
Fail-open (FO)阀回到开启位防超压 / 防憋死（冷却水阀、PSV 旁通）

🧪 技术背景速学
概念解释
Self-actuated PRV
（自力式调压阀）		完全机械结构，靠下游压力反馈推动阀芯。Fisher M-995-HP 这类。
优势：本质安全、可用于易燃易爆区；劣势：响应慢、精度低。
CV (Control Valve)气动/电动驱动 + 定位器 + DCS 信号，精度高、响应快。
两段式减压
（cascade let-down）		大压差减压（60 → 0.1 barg）单阀很难做（噪声、空化、磨损），常用"先粗减再精减"两段。
液位-流量串级外环：液位变送器 LT → PID 输出"液位想要的流量值" → 内环：质量流量控制器（自带 PID + 内置阀）按设定流量调阀位。
Free-draining / CIP 设计制药/精细化工 CIP 清洗时必须能"自重排尽"，否则有死角藏污 → GMP / CE 都会卡。

4⚠️ 气液分离器 SE01 — 本次最大新发现
🇬🇧 Keith's words
"Looking at the PID, your inlet to the separator is a dip pipe — coming in subsurface. But on the calculation Yongguang did, it's a side entry above the liquid level. These are completely different equations: one is degassing a liquid, the other is separating droplets from a gas stream. Which one are we going with?" PID 上画的是"深管"插入液面以下（脱气配置），但我们的尺寸计算却按"侧入液面以上"（除液滴配置）算的 — 完全两种不同的设备。
"Data sheet says 1 Nm³/h gas + 40 L/h liquid. But your liquid was changed to 20 L/h, and gas during reaction would only be ~20% of inlet because H2 is consumed. I worry these numbers are leading us to over-engineer the separator, and we don't have much space." 数据单的流量数据也有矛盾：液相 40 L/h 是旧值（实际已改 20 L/h），气相 1 Nm³/h 是进料量而非分离器出口的实际气量（反应消耗后约 20%）。
🎯 真实需求 — 两个问题
4-1. 流量数据自相矛盾
数据单 40 L/h（旧的 03/10 邮件数）↔ 实际定的 20 L/h ↔ PFD 也跟着改 → 数据单忘了同步更新。
1 Nm³/h 是进料量，反应消耗后 SE01 出口实际气量 ≈ 0.2 Nm³/h → 现在按 1 Nm³/h 选的 SE01 偏大。

4-2. 设计原理走错了 — 真正的设计分歧
项目 现 PID 画法（聂博 / Yongguang 原版） 现计算依据（胡超群算的）
进口位置 深管插入液面以下（dip pipe） 从容器侧面、液面以上进入
物理过程 从液体里把气脱出来（degassing） 从气体里把液滴分出来（demisting）
关键参数 气泡上升速度、停留时间 液滴沉降速度 (Stokes law)、气速 < terminal velocity
选型公式 完全不同 完全不同
🧪 气液分离器两大类设计目的（科普）
A. 从气里除液（Demister / Knockout drum） B. 从液里除气（Degasser） ↓ 气 + 雾滴 ┌─→ 干净气 ↑ ───────── │ ╱ ╲ │ ╲╲╲╲╲ ←丝网除沫 │ │ │ │ ─ ─ ─ ←液面 │ │气泡│ ←深管吹气 │ 液体 ─→ 液体出口 │ ╲水/ ─→ 脱气的液体 ↓ 关键：气速要慢于液滴沉降速度 关键：足够气泡停留时间到液面释放 典型：反应器顶部冷凝液收集 典型：脱氧 / 脱 CO2 操作
我们的工艺真正想做的是哪个？
按"连续氢化 + 气液混合反应 + 气液分离再出料"的逻辑，应该是 A. Demister（从气里除液）： 反应器出口的"湿氢气"要把夹带液体甩干，干气走顶部 vent，液体走底部进 BT04。 这种设计 inlet 应该是侧入 + vortex breaker（防涡流挡板），不是 dip pipe。 Keith 的质疑是合理的，PID 上的 dip-pipe 画法很可能是早期遗留错误。
建议：
  1. 本周内部要做的事（不用拉 Keith）：胡超群 + 范双双 + 聂博（如能联系）确认 SE01 工艺目的 — 大概率是 demister → PID 上的 dip-pipe 改成侧入 + vortex breaker → 按 demister 公式（Souders-Brown / K-factor）重算 → 流量统一为液相 20 L/h、气相按"H2 余量" ≈ 0.2 Nm³/h（再加 20% 余量）
  2. 可能的好消息：修正后 SE01 可以做小一号 → 给布局留空间，Keith 会高兴
